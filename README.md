[Curseforge](https://www.curseforge.com/wow/addons/hide-tooltips) | [Wago](https://addons.wago.io/addons/hidetooltips)

## 2. Why would I need this?

Patch 5.5.2.64133 Introduced a bug whereby certain tooltips are now anchoring to the mouse cursor instead of to the normal anchor. This makes fishing especially annoying as you have "Fishing Bobber" and the name of the pool you are casting into ontop of your fishing hook cursor thus being unable to easily see when a fish is ready to be pulled up. This addon allows you to hide those tooltips so you can see the fish splash easily. Now including hiding Mailbox tooltip as it suffers from the same issue.

## 3. What can it do?
This addon can hide tooltips for the following:

 *   Fishing Bobber
 *   Emperor Salmon School
 *   Jade Lungfish School
 *   Redbelly Mandarin School
 *   Reef Octopus Swarm
 *   Giant Mantis Shrimp Swarm
 *   Tiger Gourami School
 *   Jewel Danio School
 *   Spinefish School
 *   Krasarang Paddlefish School
 *   Shipwreck Debris
 *   Mailbox

## 4. How to use

### Minimap Icon

- Left Click to toggle the addon on/off (icon will swap from green to red to indicate status)
- Right Click to access options menu
